# The Decision Tree Check

A lead-generation quiz for Syncovate, built to run on Taft's (GoHighLevel) native Quiz Builder. Replaces the Scotoma Spotter.

Ten everyday situations. For each one the owner answers: *last time this happened, where did it land?* The result names one of three patterns (your tree holds its own weight / half the canopy is on your desk / everything runs through you), points at the heaviest branch (people, customers, money, operations), and gives one move for Monday.

Start with `WORK-PLAN.md`. Latest status and open questions are in `REPORTS.md` and `DECISIONS.md`.

The Decision Tree started years ago from Susan Scott's work at Fierce. It's grown a lot in Dr. J's hands since.
